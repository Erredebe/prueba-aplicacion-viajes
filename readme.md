# Dashboard de viajes (Angular)

Este repositorio contiene una aplicación Angular **solo frontend** con un dashboard para la gestión de un viaje privado.

## Cómo ejecutar la app

```bash
cd frontend
npm install
npm start
```

Luego abre `http://localhost:4200` en tu navegador.

## Qué incluye el dashboard

- Layout principal con navegación lateral y cabecera.
- Tarjetas de resumen del viaje (destino, estado, presupuesto, viajeros).
- Sección de **Detalles del viaje** con información de vuelos y hotel.
- Tabla de **Pasajeros** con estado, asiento y documento.
- Línea de tiempo de **Itinerario** con actividades destacadas.
- Datos mockeados mediante `TripService`.
- Estilos base en `src/styles.css`.
